## Anonymised package

`scripts/make_anonymous_package.py` builds `anonymous_package/` and `anonymous_review_package.zip` (122 files, 2.2 MB): code, archived plan and hashes, reference inputs, all result tables, reports, figures, a claim-to-output map (`ANON_README.md`), an identity-free chronology, and a hash manifest. It leaves out the decision log, README, reviews, superseded drafts and the unused author email; scans every text file for the account name, repository name, home-directory paths and the reviewing tool's name; and fails if any remain. Five reviewer files were left out by that scan (four scripts and one summary containing machine paths or the tool name); their result tables are included. Zip entries carry fixed timestamps. The paper PDF has empty author and title metadata.
