## Addendum, 17 November 2026 afternoon: Python 3.14 becomes the main environment

- **New main environment:** Python 3.14.8, DuckDB 2.0.0, pandas 3.1.1, NumPy 2.5.5, SciPy 1.18.1, Matplotlib 3.11.2 (`requirements.txt`). The previous environment is kept as `requirements-py312.txt`.
- **Run:** every script, stage by stage in `run_all.sh` order, in an empty directory, each stage exit 0, no warnings.
- **Finding:** three original-sample tables differed between the two environments. Cause: pandas 2.3's default CSV parser reads decimal numbers inexactly (in competitions 8900 and 10200, 10,387 of 41,739 public scores were one rounding step from the correctly rounded value); pandas 3.1 reads them exactly. Only `stage1_reproduce.py` and `stage2_pilot_original.py` read scores with pandas; every later stage reads them with DuckDB, which is exact, which is why all confirmatory and later results agreed to within 1e-12.
- **Fix:** both scripts now read the score columns as text and convert them with Python's `float()`, which is correctly rounded under any pandas version.
- **Effect:** in the repository's tables, `top10_mean_gap` and the top-10% tie bounds changed for competitions 8900 and 10200 (for example 0.023606 to 0.023559 in 8900), and the share of teams with positive or negative drift changed for 4493 and 5275 (a few teams' drift is exactly zero). No number in the paper changed.
- **Result after the fix:** `rebuild_py314_comparison_2026-11-17.csv`: 34 tables the same, 1 different in shape (the team-flags file explained above). `rebuild_py312_after_parsing_fix_2026-11-17.csv`: Python 3.12 environment, 33 the same, the same single exception. The two environments give the same tables.
